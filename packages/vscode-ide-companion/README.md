## 功能概览

### 1. 智能补全

分析代码的语法结构、语义关系、上下文逻辑关系以及同一项目下的其他文件，自动生成符合当前业务逻辑的行级、函数级代码。单击**Tab键**即可轻松采纳。

### 2. 智能问答

通过AI机器人回答编程中的任何问题，支持**蓝心大模型，ChatGPT4及联网搜索**功能。

### 3. 内联聊天

调用AI大模型能力对代码进行各种操作（例如优化、解释、评审、添加注释、生成测试用例等等）。

### 4. 快捷操作

- #### 生成注释

提供方法注释，类属性注释。只需点击生成注释，就可以拥有高质量的代码注释。

- #### 代码评审

提供对代码专业的评审意见，针对方法体提出编码规范，功能逻辑等各个安全等级的修改建议。

- #### 代码解释

用蓝心编码，让AI帮你理解业务代码。选中想要解释的代码片段，或者直接点击方法上的解释代码，就能帮你快速理解代码功能。

- #### 代码优化

点击快捷操作栏“优化建议”按钮，蓝心编码会对函数或者方法生成对应的优化建议。选中任意代码后点击右键的菜单栏中选择蓝心编码`->`优化建议，插件会对选中的任意代码块生成对应的优化建议。

- #### 生成单元测试

选择要测试的接口，点击单元测试可生成基于`Mockito`、`Junit`的可执行文件。

- #### 异常分析

异常处理是编码过程不可缺少的一部分内容，如果代码运行中出现异常，蓝心编码就会在打印记录中报出异常类型时直接链接到对应的异常类，还可以在日志窗口中直接查看异常类的信息。
