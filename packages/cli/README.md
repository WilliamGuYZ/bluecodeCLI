# BLUECODE CLI

![BLUECODE CLI Screenshot](./docs/assets/bluecode-screenshot.png)

蓝心编码智能终端代理 BlueCode CLI 重磅上线！
无论是交互式开发、批处理脚本，还是 CI/CD 自动化流水线，它都能无缝融入你的终端工作流，为你提供强劲的 AI 工程助力。

✨ 核心能力：
1️⃣ 全场景可用 —— 全面适配办公网及服务器环境
2️⃣ 兼顾 安全与性能—— 对接 MiniMax-M2 内部版
3️⃣ 强大的工具调用 —— 内置核心工具集，支持 MCP
4️⃣ YOLO 自动化模式 —— 任务一键托管，中途免介入
5️⃣ Shell 模式 —— AI 与终端操作自由切换

🚀 快速开始：
1、终端（bash/zsh/powershell）安装命令
npm install -g @vivo/bluecode-cli --registry=https://npm.vmic.xyz/ 
2、终端登入 Agent 命令
bluecode
